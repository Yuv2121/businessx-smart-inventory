# BusinessX: Smart Inventory, FIFO Profit & Reorder Engine

**Live demo:** [https://YOUR-LINK.vercel.app](https://businessx-smart-inventory.vercel.app/)


Built for businessman like Sunil. Works offline, with data in LocalStorage.

## What's inside
1. Rapid onboarding: master catalog, size matrix, loose items, bulk paste, voice (Hindi, Hinglish, English) with an approval checklist
2. FIFO profit ledger: batches, timeline, stock editor
3. Smart reorder engine, Siyaganj market mode and chat assistant


## Run locally
npm install
npm run dev
